# 2026-10-26 动画性能优化

本次只修改动画执行与调度。功能逻辑、界面结构、文字、图标、主题、壁纸、液态玻璃底色、透明度和模糊参数保持原样。

## 修改

- 页面切换立即开始加载，取消动画开始前的两帧等待；保留原有转场。
- 将多个整页监听合并为按相关节点变化触发，数字、计数和文本更新不再引发无关扫描。
- 设置页滚动按帧读取位置，不在每帧重复排序、反复注册观察器；离开页面清理监听。
- 滑块反馈按显示帧合并，连续输入不再强制重新布局并重播同一动画。
- 菜单只使用一套可打断的动画，结束后释放动画效果，避免旧动画长期占据样式。
- 保留卡片弹性，避免设置卡片同时运行两套入场动画。
- 放大照片的拖动按帧更新，读取布局后再绘制；按住拖动时取消原有 100ms 跟随延迟，放手与缩放仍保留原有过渡。
- 详情面板不再逐帧插值内边距，原有最终尺寸和外观不变。

## 同场景前后测试

环境：本机 Edge 无界面浏览器，1440×900，使用保留的演示项目。测试拦截所有非 GET 请求，不调用付费 AI，不改变照片结论或服务器设置。

| 操作 | 优化前 | 优化后 |
|---|---:|---:|
| 打开设置：布局计算次数 | 51 | 25 |
| 切换缩略图密度：布局计算次数 | 19 | 5 |
| 连续拖动滑块：布局计算次数 | 317 | 46 |
| 连续拖动滑块：全页查询次数 | 90 | 0 |
| 滚动设置页：位置读取次数 | 2636 | 324 |

以上是同一合成操作的浏览器开销比较，不代表原生窗口稳定帧率承诺。原始结果见 `before.json`、`after.json`，交互回归见 `regression.json`。

## 外观与范围核对

设置页稳定后的面板/按钮位置、尺寸、颜色、背景、边框、阴影和模糊参数逐项相同。截图仅设置导航指示器附近存在少量栅格差异。所有玻璃材质 CSS 声明保持一致；其余 73 个应用文件哈希未变。

修改的应用文件只有 `app.js`、`release-motion.js`、`release-motion.css`、`index.html`。原始副本位于项目 `backups/animation-performance-20261026`；同目录中保存同步前的便携程序资源。

原有设计检查器对弹性曲线及动态赋值图片有提示，且不能解析服务器 `/static/` 路径；本次依照用户要求保留既有风格，以实际浏览器结果核对外观。

源码与 `dist/拾影` 的现有程序资源同步更新。无需迁移项目，关闭并重新打开原程序即可载入。既有安装包和压缩包未重新生成。
