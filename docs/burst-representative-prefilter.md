# 单轮 API 粗筛：本地连拍精选 + 一次精筛

## 导入与判断分开

- 导入只负责扫描、读取元数据、生成缩略图；
- 导入完成后再点“开始粗筛”，不自动触发；
- 分析开始后，只有全部粗筛结束才显示人工复筛界面。

## 本地连拍精选

- 同来源；
- CLIP ViT-B/32（float32）场景向量余弦 ≥ 0.78；
- 人物用 YuNet + SFace 的所有检出人脸集合比较，任一人脸余弦 ≥ 0.30；
- 同时和组首比较，避免连续相似链串场；
- 时间只用于排序，不作硬门槛；
- 每组本地只保留排名最高的 1 张；
- 同组其余照片**立即**标记为连拍重复、决策设为待确认，不等 API 结束。

## 一次 API 精筛

- 送 API 的只有：
  1. 每个连拍组本地选出的 1 张；
  2. 所有非连拍照片。
- 不再有第一轮快速粗筛，也没有“保留后再送第二轮”。
- 一次调用完成五类检查，结果直接写入照片和决策。
- 全部候选处理完、任务状态变为 `done` 后，才显示人工复筛界面。

## 进度

- 本地向量/分组进度显示在“连拍精简”卡片；
- API 精筛进度显示在“AI 初筛”卡片；
- 不使用右下角浮层进度小窗口。

## 代码位置

- `app/scene_embeddings.py`：CLIP 场景向量
- `app/faces.py`：YuNet/SFace 多脸检测与特征
- `app/dedupe.py`：场景 + 人脸分组与排名
- `app/two_stage.py`：本地精选 + 一次 API 精筛
- `app/analysis.py`：独立分析任务、暂停/继续
- `app/importer.py`：只负责导入/预览
- `app/web/app.js`：连拍精筛进度、AI 进度、完成后才显示人工复核
